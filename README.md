# Machine Learning QSPR Analysis of Alzheimer's Compounds

This repository contains the supplementary data and Python scripts supporting our quantitative structure-property relationship (QSPR) analysis. The study models 14 physicochemical properties of 28 Alzheimer's therapeutic compounds using six 2D eccentricity-based topological indices and advanced machine learning algorithms.

## Repository Contents

### 1. Code Scripts
The computational methodology is provided in plain text format to ensure maximum accessibility. These scripts can be copied directly into any Python environment (such as Google Colab, Jupyter Notebook, or a local IDE) for execution.
* **indices.txt**: Script for processing and computing the eccentricity-based topological indices.
* **models.txt**: Script containing the leak-free nested cross-validation pipeline, hyperparameter optimization, and machine learning algorithm training (FANN, Random Forest, XGBoost, GBR, and SVR).
* **plot.txt**: Script for generating the performance evaluation graphs, correlation heatmaps, and MLR breaking-point analysis.

### 2. Required Input Data
The following datasets are mandatory for executing the corresponding Python scripts. **Important:** These files must remain exactly as provided and should not be altered in any way. The scripts rely heavily on their specific column formatting and structural integrity to run without errors.
* **alz.xlsx**: Required to run `indices.txt`.*(Note: This dataset also contains the official SMILES codes for all 28 compounds analyzed in this study).*
* **Master_Dataset_with_Indices.xlsx**: Required to run `models.txt`.
* **QSPR_Results.xlsx**: Required to run `plot.txt`.

### 3. Generated Results
The repository includes the final calculated outputs for verification and reference. These files are purely resultant data and are not used as inputs for any of the code scripts:
* **predicted.xlsx**: The exact numerical predictions generated by the optimized machine learning models across all 14 physicochemical properties.

## Execution Instructions
To reproduce the findings presented in the manuscript:
1. Download the required input data files and ensure they are placed in the active working directory of your Python environment.
2. Copy the code from the desired `.txt` file and run it. 
3. Ensure all necessary dependencies are installed prior to execution.

## Required Python Libraries
To run the machine learning models and generate the plots successfully, standard computational libraries must be installed in your environment:
* pandas
* numpy
* scikit-learn
* xgboost
* matplotlib
* seaborn
